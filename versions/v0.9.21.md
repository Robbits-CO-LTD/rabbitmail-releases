# RabbitMail v0.9.21

Signed Windows release of RabbitMail v0.9.21.
Source commit: 819ce06ae4506f333d1e979daf8321bbe65e5b3a

## 変更点

### AIでの返信案作成

AIチャットに「英語で返信して」「短く返信して」「丁寧に返信して」と頼むと、指定に沿った返信案を作成します。表示中のメールと、検索して選んだメールのどちらにも使えます。

### 改善

- Proの危険度チェックが有効なとき、受信トレイのメールのなりすまし判定を保存するようにしました。同じ場所のメールが入れ替わった場合は、新しいメールの判定に更新します。
- 複数のメールの返信マークをまとめて処理するとき、同じ会話を繰り返し読み込む処理を減らしました。

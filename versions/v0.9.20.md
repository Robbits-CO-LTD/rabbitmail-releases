# RabbitMail v0.9.20

Signed Windows release of RabbitMail v0.9.20.
Source commit: 8a045677933b10cd4bead34286a55364772b3609

## 変更点

### 機能追加・改善

- AIチャットでRabbitMailの使い方を聞くと、アプリに同梱した操作ガイドの内容で答えるようにしました。出てきた候補を押すと、そのガイドを開けます。AIモデルを準備している場合、RabbitMailについての質問でガイドに当てはまる項目が無いときは、推測で答えずに、案内が無いことを理由とあわせて伝えます。
- AIの返信案を、ビジネスメールの形（宛名・あいさつ・本文・結び）で作るようにしました。
- 日本語の画面で、件名にも本文にも日本語が無い英語だけのメールに返信案を作るときは、英語で作るようにしました。日本語が少しでも含まれるメールは、これまでどおり日本語で作ります。
- 作成画面の「返信案」「署名」「添付」の操作を、3つのボタンにまとめました。新しく書くメールには、返信案のボタンを出しません。
- 署名の編集画面で「この署名を使う」を押すと、開いている下書きの署名を入れ替えるようにしました。入れ替えられないときは、その理由をお知らせします。
- 作成画面の件名を、見出しの付いた入力欄にして、直し忘れに気づきやすくしました。
- 作成画面の宛先・Cc・Bccで、入力中の文字がアドレスの札や枠線に詰まらないよう、余白を付けました。
- 口座の状態の表示で、送信を確かめていない口座は「送信 未確認」と表示し、「送信を確かめる」から確かめられるようにしました。受信の確認だけでは、送信も問題ないとは表示しません。
- カンバンで承認した後に送信が止まったときも、送り方を選び直して送れるようにしました。
- 判定待ちの一覧で、読み込んだ範囲の外にあるメールも補って表示し、その場で判定できるようにしました。
- 本文検索の途中でも、新しく見つかったメールから順に表示するようにしました。
- 前の返信案の一部を表示できなかったときに、案内を表示するようにしました。
- 添付を追加できなかったときは、添付の失敗として案内するようにしました。
- 件名が空のメールは、確認を済ませたときだけ送るようにしました。確認の画面を通らない経路からは送られません。
- 受信メールのなりすましの危険度を判定する機能と、返信が必要なメールを見分ける機能の準備を進めました（画面の見え方はまだ変わりません）。

### 不具合修正

- 送信状況の時刻が、読みにくい形式のまま表示されることがある問題を修正しました。
- 「閉じる」の動きをAIに頼んで保存している最中に×を押すと、古い設定のまま終了または常駐することがある問題を修正しました。
- 更新の定期確認で、ダウンロード済みの同じ版をもう一度ダウンロードしないようにしました。
- サーバーから取り込んだ下書きの本文で、改行の形がそろわない問題を修正しました。
- 翻訳・要約を止めたときに、後片付けが残ることがある問題を修正しました。
- 下書きを保存した後に返信先のメールが消えた場合の扱いを、手で保存したときとAIで編集したときでそろえました。
- メールの見出しを読み直すときに、別のメールの失敗まで続けての失敗として数えてしまう問題を修正しました。
- 本文検索の途中でログイン情報が更新されたときに、新しい接続が閉じられたり、検索が使えなくなったりすることがある問題を修正しました。
- 接続確認待ちの口座で、保存していたログイン情報が消えて元に戻ったあとに、確認待ちが外れてしまうことがある問題を修正しました。
- メールの多い口座で、まとめての操作の最中に、ほかの処理が待たされて画面の動きが重くなることがある問題を減らしました。
- 暗号やファイルの処理に使っている部品を、新しい版に更新しました。

### ご利用上の注意

- 送信を確かめた記録の無い口座は、更新の後に「送信 未確認」と表示されます。「送信を確かめる」で確かめると、表示が変わります。
- GmailのOAuthによる新規口座登録は、引き続き「準備中」と表示されます。

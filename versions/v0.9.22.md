# RabbitMail v0.9.22

Signed Windows release of RabbitMail v0.9.22.
Source commit: 2a3f1b9bc41da44d0ad7847e1cbdd135c103be0c

## 変更点

- 予約した下書きを開き直したとき、作成画面とカンバンで同じ予約日時を表示するようにしました。日時を表示できない場合も予約のまま開き、意図せず「今すぐ送信」に切り替わることを防ぎます。
- カンバンからの送信が拒否された場合、送信待ちに登録されなかったことが分かるようにしました。
- 送信者をブロックできないとき、返信案を作成できないとき、送信や予約を受け付けられないときの案内を分かりやすくしました。

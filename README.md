# RabbitMail 配布ファイル

RabbitMailのWindows用インストーラーと、アプリ内アップデート用ファイルを配布するためのリポジトリです。アプリのソースコードは含みません。

公式サイト: https://lp.rabbitmail-ai.com/

## ダウンロード・更新

- [最新版をダウンロード](https://github.com/Robbits-CO-LTD/rabbitmail-releases/releases/latest)
- [公開済みリリースの一覧](https://github.com/Robbits-CO-LTD/rabbitmail-releases/releases)

新規インストールは各リリースの Windows 用インストーラー（MSI）から、対応するインストール済みアプリの更新はアプリ内の「アップデート」ボタンから行えます。

AIモデルはインストーラーに同梱せず、ユーザーがアプリ内で選択してダウンロードする方式です。

## リリースノート

0.9以降にこのリポジトリで公開したバージョンを、新しい順に掲載しています。バージョンをクリックすると変更点が開きます。公開日は日本時間（JST）です。

<details>
<summary><strong>v0.9.6</strong> — 2026年10月24日公開</summary>

### 機能追加・改善

- メール口座が1件もないときに、AIチャットから最初の口座を登録できるようにしました。パスワードはAIに渡らず、確認するまで口座は作られません。途中で設定から口座を追加した場合は、設定での追加を優先します。
- 外部画像の読み込みが期限切れで取れなかったときに、理由と「画像をもう一度読み込む」を表示するようにしました。

### 不具合修正

- 外部画像を許可したあとの開き直しや期限切れの後に、表示済みの画像と読み込みの操作が消えることがある問題を修正しました。
- 削除した口座の古い会話が、旧版の保存データから再起動後に戻ることがある問題を修正しました。
- サンプル口座に関する古い設定の競合のせいで、旧版向けの設定の書き出しが止まり続ける問題を修正しました。止まっている理由は設定画面に表示します。
- AIの書き直しで、元の本文にない国際化ドメイン名（例: pay.みんな）が足された場合は、保存前に止めるようにしました。
- 依存ライブラリを更新しました。

### ご利用上の注意

- HTML形式のメール本文内リンクは、この版ではまだ有効化していません。
- GmailのOAuthによる新規口座登録は、引き続き「準備中」と表示されます。

[ダウンロード・配布情報](https://github.com/Robbits-CO-LTD/rabbitmail-releases/releases/tag/v0.9.6)

</details>

<details>
<summary><strong>v0.9.5</strong> — 2026年10月23日公開</summary>

### 機能追加・改善

- 返信済みのメールを、カンバンの「要返信」に自動で並べないようにしました。メールサーバーの返信済みの情報と、このアプリから送った返信の両方を記録します。メールを開いた画面には「返信済み」とその根拠を表示します。
- 設定の「ブロックした送信者」で、読み取れない登録を、確認のうえ1件ずつ解除できるようにしました。メールは削除せず、移動済みのメールも元に戻りません。
- Gemma 4 12Bでも、チャットの指示で下書きを書き直せるようにしました（GPUでの利用を推奨します）。

### 不具合修正

- 送信者をブロックし直したときに、同じメールへの迷惑メールへの移動が重ねて予約される問題を修正しました。差出人が複数のメールのブロック解除や、移動できなくなった予約の扱いも改善しました。
- 外部画像の許可を取り消したとき、そのメールの表示もブロックの案内とボタンに戻るようにしました。
- メールを開く・右クリック・AIの検索結果から変えた既読の表示が、その後の実際の状態を隠すことがある問題を修正しました。
- カンバンで「要返信」以外のレーンに置いたカードが、読み込み範囲の外に出ると消える問題を修正しました。
- AIチャットで「受信トレイをすべて既読に」と頼んだときも、一括既読の確認カードを表示するようにしました。
- 依存ライブラリを更新しました。

### ご利用上の注意

- HTML形式のメール本文内リンクは、この版ではまだ有効化していません。
- GmailのOAuthによる新規口座登録は、引き続き「準備中」と表示されます。

[ダウンロード・配布情報](https://github.com/Robbits-CO-LTD/rabbitmail-releases/releases/tag/v0.9.5)

</details>

<details>
<summary><strong>v0.9.4</strong> — 2026年10月22日公開</summary>

### 機能追加・改善

- AIチャットから返信案を下書き本文へ反映し、指示に沿って書き直したり、元に戻したりできるようにしました。書き直しには対応するローカルAIモデルが必要です。
- テキスト形式のメール本文にあるURLを、確認画面を経て外部ブラウザーで開けるようにしました。
- 送信済み・下書き・迷惑メール・アーカイブ・ごみ箱の各フォルダーでも、一括既読を使えるようにしました。
- 口座のポート番号と暗号化方式の食い違いを、保存前や接続失敗時に案内するようにしました。AIチャットでも設定を確認し、確認付きで変更できます。
- 前回確認した未読数を保存し、起動直後に暫定値として表示するようにしました。
- 同梱サンプル口座を表示せず、口座が0件の状態から使い始められるようにしました。

### 不具合修正

- 送信を受け付けたときに送信処理を起動し、定期巡回まで待たされる問題を改善しました。
- 受信トレイを開いていない口座でも、カンバンに未読メールを並べられるようにしました。未読だけのカードとAI返信案の対象を見分けやすくし、カードから要返信マークを変更できます。
- 送信者アイコンの整理で、分類不明の結果を保存できず失敗が残る問題を修正しました。
- 無効化中のHTMLメール内リンクを押した際に、意図しない接続が始まる問題に対応しました。

### ご利用上の注意

- HTML形式のメール本文内リンクは、この版ではまだ有効化していません。
- GmailのOAuthによる新規口座登録は「準備中」と表示されます。既存口座の同期や再認証とは別の制限です。

[ダウンロード・配布情報](https://github.com/Robbits-CO-LTD/rabbitmail-releases/releases/tag/v0.9.4)

</details>

<details>
<summary><strong>v0.9.3</strong> — 2026年10月21日公開</summary>

### 機能追加・改善

- ステータスバーに、AIが取り組んでいる作業と返信案の待ち状況を表示するようにしました。翻訳・要約などでAIが使用中の場合も、待っている理由をチャットに表示します。
- Windowsのタスクバーアイコンに、受信トレイの未読数を表示するようにしました。
- 開き直したメール本文をメモリ上のキャッシュから表示し、再取得の待ち時間を減らしました。
- Gemma 4の3モデルで確認済みの用途を公開し、12BモデルにはGPU推奨の案内を追加しました。

### 不具合修正

- 下書きの保存状態を高さ固定の1行にまとめ、入力中の表示の揺れを抑えました。
- 下書きの古いコピーを確認中に編集が進んだ場合も、最新版の保存へ進むようにしました。再確認失敗時の警告表示も改善しました。
- 未読数の取り直し中も前の件数を表示し、サイドバーのちらつきを抑えました。
- 検索演出中にフォルダーや作業モードを切り替えた場合、古い演出が続かないようにしました。
- POP3メールの識別子を画面と内部処理の間で正確に受け渡し、大きな値が丸められる問題を修正しました。

[ダウンロード・配布情報](https://github.com/Robbits-CO-LTD/rabbitmail-releases/releases/tag/v0.9.3)

</details>
